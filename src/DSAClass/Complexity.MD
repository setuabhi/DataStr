1. When it will take O(1), O(n), O(log(n)), O(nlog(n)), O(n^2)


Answers:
O(1): fetching array data based on index or fetch from hashmap
O(n): Searching an element in an array
O(log(n)): Size decreases by 1/2 in each iteration
O(nlog(n)): Merge sort and Quick Sort
O(n^2): same element iterated n times, Bubble sort
